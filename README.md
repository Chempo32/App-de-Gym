# 🏋️‍♂️ GymProgress

GymProgress es una aplicación móvil diseñada para ayudar a los usuarios a registrar, organizar y hacer un seguimiento de sus sesiones de entrenamiento en el gimnasio de forma intuitiva.

## ✨ Características Principales

* **Gestión de Rutinas:** Crea rutinas de entrenamiento personalizadas (ej. "Día de Pierna", "Lunes de Pecho").
* **Patrón Acumulador de Ejercicios:** Añade múltiples ejercicios a una misma rutina temporalmente antes de guardarla por completo.
* **Historial Persistente:** Todo el progreso y las rutinas se guardan de forma permanente en la memoria del dispositivo.
* **Interfaz de Usuario (UI):** Diseño limpio enfocado en la experiencia del usuario, con soporte integrado para **Modo Oscuro (Dark Mode)**.

## 🛠️ Tecnologías Utilizadas (Frontend)

Este proyecto está construido íntegramente con tecnologías web y móviles modernas:
* **React Native:** Framework principal para el desarrollo de la interfaz móvil.
* **JavaScript:** Lógica de la aplicación y manejo de estados.
* **Expo:** Entorno de desarrollo y compilación.
* **React Navigation:** Manejo del menú lateral (Drawer) y la navegación entre pantallas.
* **AsyncStorage:** Base de datos local para la persistencia de la información del usuario.
